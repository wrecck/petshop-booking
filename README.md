# Paws & Co. Booking

A responsive customer booking experience for pet grooming businesses.

## Features

- Service and groomer selection
- Live monthly availability calendar
- Selectable appointment time slots
- Customer and pet details form
- Booking summary and confirmation
- Responsive desktop and mobile layouts

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
